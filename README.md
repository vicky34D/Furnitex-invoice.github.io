Furnitex Mukundapur - Quotation Generator
A simple, powerful, and modern web-based quotation generator designed for Furnitex Mukundapur. This tool allows for the quick creation of detailed, professional invoices directly in the browser, with the ability to download them as PDFs. It's built with vanilla JavaScript and requires no backend, making it incredibly easy to deploy and use.

✨ Features
Dynamic Quotation Table: Easily add or remove line items with a single click. Serial numbers are updated automatically.

Smart Measurement Calculation: The "Measurement" field can evaluate mathematical expressions like 7*7 or 8ft x 4ft to automatically calculate the total square footage.

Automatic Price Calculation: Prices are calculated in real-time (Measurement * Rate), but can also be manually overridden for special cases.

Fully Customizable Fields: Every dropdown (Particulars, Rate, Remarks) includes a "Custom..." option, allowing you to enter non-standard text for ultimate flexibility.

Service & Quantity Support: Items like "Repairing" or "Wood Polish" are treated as quantities (Qty:) instead of square feet, providing accurate descriptions.

Professional PDF Invoices: Generate and download clean, professional-looking PDF invoices complete with customer details, company branding, and a detailed breakdown of items.

Client-Side Operation: The entire application runs in the web browser. No internet connection is needed after the page has loaded, and no data is sent to a server.

Modern UI: Styled with Tailwind CSS for a clean, responsive, and user-friendly interface.

🚀 How to Use
Open the File: Simply open the index.html file in any modern web browser (like Chrome, Firefox, or Edge).

Add Items: Click the + Add Item button to add rows to your quotation.

Fill Details:

Select an item from the "Particulars" dropdown or choose "Custom..." to type a unique item name.

Enter the dimensions in the "Measurement Details" column (e.g., 7*7). The result will be calculated and displayed instantly.

Select a "Per Sqft Rate" or enter a custom one.

The "Price" will be calculated automatically. You can click on it and type a new number to override it.

Enter Customer Information: Fill in the customer's name and address at the bottom.

Download PDF: Click the Download Invoice (PDF) button to save the final quotation to your device.

🛠️ Technologies Used
HTML5: The core structure of the web page.

Tailwind CSS: For all styling and creating a responsive layout.

JavaScript (ES6+): For all the application logic, calculations, and interactivity.

jsPDF & jsPDF-AutoTable: Libraries used for generating the final PDF document directly in the browser.
